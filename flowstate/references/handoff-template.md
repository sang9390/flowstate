# handoff 문서 양식

파일명: `HANDOFF-<YYYY-MM-DD>.md` (프로젝트 루트). 아래 양식을 채워 생성한다.

```markdown
# Handoff — <날짜>

## 목표
<이 작업 흐름의 루트 목표 한 줄>

## 완료된 것
- <완료 항목 + 검증 방법>

## 진행 중 / 미완
- <항목 + 현재 상태 + 막힌 지점>

## 유효한 사실 (facts.md ACTIVE 스냅샷 요약)
<핵심 사실 5~10줄. 전체는 .flowstate/facts.md 참조>

## 이번에 철회된 사실
- <철회 사실 + 이유> (없으면 "없음")

## 다음 세션 시작 지점
1. <가장 먼저 할 일>
2. <그 다음>

## 주의사항
- <파괴적 작업 예약, 미해결 질문 등>
```

규칙: 추측 금지 — facts.md에 근거 없는 내용은 쓰지 않는다. 생성 후 상태 줄에 파일 경로를 출력한다.
